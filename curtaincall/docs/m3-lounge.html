M2 종료(2026-11-06) 이후 대기실 구조가 어떻게 바뀌었는지와 새로 생긴 지역을 정리한 문서입니다. 기준은 최신 dev의 구현(대기실 씬·공간 프리팹·코드·설정값)이고, 좌표와 치수 일부는 작업 기록(Task log)에 적힌 값입니다. 기획 의도가 기록에 남아 있지 않은 곳은 "의도 기록 없음"으로 두었고, 맨 아래 "확인이 필요한 빈칸"에 모았습니다.

1. 한눈에 보는 변경

  • 열쇠 동선 폐기. 열쇠 6종, 비밀번호 패드, 공연 기록, 기계실 배관함을 대기실 씬에서 지웠습니다. 길을 여는 수단은 맨몸·천막 말뚝 뽑개로 부수기, 휴대 절단기로 배선 끊기, 배터리로 전력 넣기, 2인 목마로 오르기입니다.
  • 방 맞바꿈. 무대 입구 통로를 로비 북쪽으로, 작업실·소품실을 로비 남쪽 전실 양옆으로 옮겼습니다. 방 내부와 크기는 그대로입니다.
  • 신규 지역 8곳. 전실, 뒤쪽 복도, 이전 세대 생활 장소, 창고, 기계실 입구(설비실), 숨겨진 방 1·2, 숙소 녹슨 벽 방.
  • 최종 탈출 동선 확정. 숙소 환풍구에서 시작해 관리실 컴퓨터와 배선 절단을 거쳐 탈출로 문이 열립니다.
  • 방 24곳 공간 프리팹화. 씬 용량이 74MB에서 16MB로 줄었습니다. 신규 지역은 프리팹이 아니라 대기실 씬 안에만 있습니다.

2. 최종 탈출 동선

  1. 숙소 환풍구(2인 목마) → 설비실 → 지하 기계실 캣워크
  2. 계단실 뒤쪽 빗장 파괴 → 로비와 지하가 계단으로 연결
  3. 숙소 화장실 녹슨 벽 파괴 → 폐기물 보관소 → 배관 구역 → 뒤쪽 복도 → 이전 세대 생활 장소
  4. 창고 창문 → 무대 장치 보관실(한 방향 숏컷) → 휴대 절단기 획득
  5. 기계실 녹슨 벽 파괴 → 관리실 배선 절단(또는 안쪽 빗장, 키 카드) → 관리실 문 열림
  6. 관리실 컴퓨터에 날짜 20240912와 암구호 RUN 입력
  7. 탈출로 배선 4가닥 절단 → 정전 1회 → 나가는 길 개방 연출 → 탈출로 입구에 전원 집결

나가는 길은 관리실 컴퓨터, 탈출로 배선 4가닥, 관리실 배선 1가닥이 모두 충족돼야 열립니다. 숏컷은 한 번 열면 계속 열려 있지만, 탐색 진행은 세대가 바뀌면 초기화됩니다.

5. 신규 지역 상세

공통 규칙: 부수기는 F를 누르고 있는 동안 게이지가 차는 방식입니다. 아래 "맨몸 n / 뽑개 n"에서 맨몸 1은 1.5초, 뽑개는 맨몸의 5배 빠르기입니다(맨몸 3 = 4.5초, 맨몸 6 = 9초, 맨몸 15 = 22.5초). 손을 떼도 진행은 유지되고, 뽑개는 대상이 부서질 때만 내구도 1을 씁니다. 꽝은 없습니다.

5-1. 전실과 전기 문 (작업실·소품실 입구)

기획 의도 이동 중 자연스럽게 탐색을 배우도록 기물과 방을 둔다(Task-126 계획). 꽝 없음.
잠금 전기 문. 문 왼쪽 동력 소켓에 배터리를 꽂으면 열리고 빼면 닫힙니다. 배터리는 닳지 않고 로비 쪽에서만 닿습니다.
영구 개방 작업실 동벽 배관함(맨몸 3 / 뽑개 1)을 부수면 회로가 드러나고, 회로(맨몸 3 / 뽑개 1)를 부수면 문이 열린 채 고정됩니다. 조명이 3초 깜빡이고 알림 조명이 노란색으로 바뀝니다.
배터리 로비 쓰레기 더미에 1개뿐입니다.
연동 회로를 고장 내면 상점의 공연 기물 4종 구매가 풀립니다.
추격자 작업실 1, 소품실 2, 전실 0

진입 화장실 녹슨 벽 → 배관 구역 → 배관 연결 통로 서쪽 끝. 자체 잠금 없음.

5-5. 기계실 입구(설비실)와 숙소 환풍구

기획 의도 숙소 환풍구에서 지하 기계실로 이어지는 길(Task-115 계획). 입구 높이를 혼자서는 닿지 않게 잡아 2인 목마를 전제로 합니다.
