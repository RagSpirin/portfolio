M2 종료(2026-11-06) 이후 추가하거나 바꾼 튜토리얼과 학습 요소를 정리한 문서입니다. 기준은 최신 dev의 구현이고, 안내 문구는 화면에 실제로 나오는 문구입니다. 기획 의도는 작업 문서에 기록된 것만 옮겼고, 기록이 없는 곳은 "의도 기록 없음"으로 두었습니다.

1. 전체 흐름과 구역 잠금

1일차 순서: 서명 → 최초 외줄타기 리허설(연습실, 5구간) → 무대 입구 집결 → 첫 외줄 공연 → 대기실 복귀 → 대기실 튜토리얼 전원 확인 → 탐색 시간 시작 → 두 번째 공연 → 1일차 밤 안내 → 취침.

구간 닫히는 곳 그 밖의 제한
A. 리허설 ~ 첫 공연 종료 작업실·소품실 전실 입구, 북동쪽 상점 홀, 숙소, 연습실 통로, 작업실 갈림길, 화물, 지하. 무대 입구 통로는 리허설을 마치면 열림 대기실 상호작용 전체 잠김
B. 첫 공연 뒤 복귀 ~ 튜토리얼 전원 확인 숙소, 작업실·소품실 전실, 작업실 갈림길, 연습실 통로 숙소 문 연출, 녹슨 벽 발견 연출, 잠긴 문·환풍구·연습실 안내 모두 차단
C. 전원 확인 뒤 철창이 말려 올라감(1.6초) 숙소 입구에 처음 들어서면 숙소 문 이벤트 시작
  • 닫힌 구역 안에 있는 캐릭터는 로비 출발 자리로 옮깁니다.
  • 철창 높이 5.5m, 투명 벽 12m, 투명 벽 두께 1.2m입니다(목마와 점프로 넘는 것을 막기 위한 값).
  • 잠금 여부는 모두가 공유하는 런 상태로 정하므로 호스트와 게스트가 같은 상태를 봅니다.
  • 리허설을 건너뛰는 개발용 시작에는 잠금이 걸리지 않습니다.

기록된 의도: 숙소 문 연출, 녹슨 벽 발견 연출, 작업실·소품실 문 안내가 "첫 외줄 공연 → 대기실 복귀 → 대기실 튜토리얼 전원 확인" 뒤부터 나오게 한다(11/15). 그렇게 하는 이유는 기록 없음.

2. 게임 튜토리얼 — 최초 외줄타기 리허설

위치·대상 연습실 링 위. 런 시작 직후 전원 참가. 호스트가 완료와 추락 복구를 판정해 공유
소개 문구 외줄 타기 리허설 / 안내에 따라 리허설을 진행합니다. (추락 시 출발점에서 다시 시작)
실패 처리 추락하면 "추락 / 추락하여 구간 출발점에서 다시 시작합니다." 1.5초 뒤 온전한 몸으로 복귀(부상 없음). 포기 불가
구간 넘기기 "구간 넘기기 / 과반수가 동의하면 현재 구간을 넘깁니다." (4명 3표, 3명 2표, 2명 2표)
완료 "리허설 완료 / 바닥의 길안내를 따라 무대 입구로 이동합니다. 모든 단원이 모이면 첫 공연이 시작됩니다."
M2 / M3 M2에 제작. M3에 문구 덮어쓰기, 단색 펄스 길안내로 교체, 재연습 삭제(자유 연습으로 대체)
구간 안내 문구 목표 완료 규칙
1 · 외줄 건너기 줄 위에서는 균형 키를 눌러 균형을 유지합니다. 전진 키를 눌러 앞뒤로 이동합니다. 끊긴 줄을 건너 도착 지점까지 이동 전원 도착 또는 1명 도착 후 과반 동의
2 · 그네타고 건너기 그네 앞에서 상호작용 키를 눌러 그네를 잡습니다. 전진 키로 반동을 주고 점프 키를 눌러 점프합니다. 그네를 타고 건너편 줄에 착지 같음
3 · 연속으로 그네 타기 그네에 매달린 채 반동을 주고 점프합니다. 체공 중 다음 그네 가까이에서 상호작용 키를 눌러 탑승합니다. 그네를 연속으로 갈아타기 같음
4 · 트리거 그네 트리거 그네는 탑승 시 끊어진 줄을 이을 수 있습니다. 이어지는 줄은 탑승 시마다 달라집니다. 트리거 그네로 끊긴 줄 잇기 1명 도착 즉시
5 · 목마로 더 높은 그네에 탑승하기 단원 근처에서 상호작용 키를 눌러 목마를 타면 더 높은 곳에 있는 그네를 탈 수 있습니다. 그네에 탑승한 단원 근처에서는 다리에 매달릴 수 있습니다. 목마로 동료와 첫 그네에 매달리기 전원 도착 또는 과반 동의

가르치는 것: 외줄 균형과 이동, 그네 잡기·반동·점프, 연속 그네, 트리거 그네, 목마와 매달리기.

기록된 의도: 기존 공연 시스템으로 리허설을 구성한다. 실제 공연에는 퀘스트를 추가하지 않는다. 길안내는 물리적 황동·직물 표현이 배경과 구분이 약해 강한 단색으로 다시 만들었다.

2-1. 인간대포 리허설 (대기실 연결부)

  • 인간대포를 해금하면 호스트에게 "새 공연 해금 / 인간대포 공연이 해금되었습니다. 지금 리허설로 이동할까요?"가 뜹니다.
  • 미이수 상태로 쉬는 시간이 시작되면 다시 안내합니다. 추격전 중에는 진행할 수 없습니다.
  • 리허설 동안 쉬는 시간 타이머가 멈추고, 복귀 때 남은 시간이 1분 미만이면 1분을 더합니다(M3).
  • 원칙: 신규 기물·시스템 없이 기존 인간대포 공연 에셋과 시스템을 차용하고 세부 기획만 리허설에 맞춥니다.

3. 대기실 튜토리얼 (안내 G · N · S)

M2에 만들었고 M3에 규칙과 문구를 고쳤습니다. 각자 자기 화면에서 보는 개인별 진행이며, 본 안내는 게임을 끌 때까지 다시 나오지 않습니다. 안내 패널은 화면 왼쪽(시계 아래)에 뜹니다.

기록된 의도

  • 플레이테스트에서 "다음 행동을 모름"이 다수였다. 진행자 설명 없이 다음 행동과 목적지를 찾아가는지가 통과 기준이다.
  • 진행은 개인별이고, 팀 사건(공연 해금, 동료 사망 등)은 모두에게 반응한다.
  • 인간 대포는 "숨은 공연 기물이 있다"는 존재만 알리고 위치는 알리지 않는다.
  • 탐색 퍼즐은 단서·도구의 쓰임까지만 알리고 탈출 해법은 알려 주지 않는다.
  • M3(11/17) 규칙: 해금되지 않은 장소는 안내로 보여 주지 않고 해금 뒤에 띄운다. 문이 열리는 연출이 끝난 뒤 안내를 시작한다.

4. 숙소 튜토리얼 (전부 M3)

위치 로비 동쪽 숙소 입구 통로와 숙소 내부
시작 조건 대기실 튜토리얼 전원 확인 뒤. 발동은 호스트가 판정하고 전원 화면에서 같은 연출을 재생
재노출 세대가 바뀌어도 다시 나오지 않고, 새 게임에서는 다시 나옴. 늦게 들어온 사람은 끝난 연출을 다시 보지 않음
단계 플레이어 행동 안내 문구 완료 조건·예외
1. 문 오작동 누군가 숙소 입구 통로에 들어섬 숙소 문 / 절단기를 이용해 배선을 끊어 숙소 문을 여세요. 문이 닫혔다 덜컹거림 2.4초 → 녹슨 휴대 절단기가 넘어짐 0.7초 → 절단기 클로즈업 → 끊을 배선 2.6초 → 복귀 0.8초. 건너뛰기 없음. 연출 중 조작 잠금, 추격자·탐색 시간 정지. 문 안쪽에 있던 사람은 문 밖으로 이동
2. 닫힌 문 확인 닫힌 문에 다가감 휴대 절단기를 이용해 전력을 끊어야 합니다. 키 버튼 없는 설명
3. 배선 절단 녹슨 휴대 절단기로 입구 북쪽 로비 벽의 배선을 맞힘 없음 문이 1.2초에 걸쳐 열림. 일반 휴대 절단기로는 못 자름
4. 절단기 소멸 없음 기물 파괴 알림(녹슨 휴대 절단기) 문이 열리고 1.5초 뒤
5. 녹슨 벽 발견 숙소 북쪽 벽 앞에 들어섬 상호작용 가능한 기물 / 상호작용 가능한 기물이 존재합니다. 맨몸, 혹은 적합한 도구를 선택한 후 F를 눌러 대상에 상호작용하세요. 벽 클로즈업 4.5초. 벽이 이미 부서져 있으면 재생 안 함
6. 녹슨 벽 부수기 F를 계속 눌러 게이지를 채움(맨몸 9초) 또는 천막 말뚝 뽑개 녹슨 벽 · F키로 상호작용 하기 보상: 10원 토큰 5개, 천막 말뚝 뽑개 1개. 진행은 팀 공유
7. TV 첫 접근 TV 화면 앞 3m 안에 들어섬 없음(흑백 노이즈 3초 뒤 꺼짐) 게임 실행 중 1회
8. TV 테이프 비디오 테이프를 들고 TV에 F. 켜진 동안 F 짧게 = 화면 보기, F 길게(0.8초) = 꺼내기 재생할 테이프가 필요할 것 같다. / ESC·F·마우스 우클릭: 나가기 F 꾹 누르기: 비디오 테이프 꺼내기 넣은 동안 영상 반복 재생
9. 환풍구 2인 목마로 환풍구에 올라 앉아서 이동 좁은 통로 / 좁은 곳에서는 Ctrl키로 앉아서 이동하세요. 환풍구 안 두 곳에서 근접 시 1회

가르치는 것: 휴대 절단기로 배선을 끊어 문을 여는 법, 부술 수 있는 기물이 있다는 것과 부수는 조작(F 길게), 넣고 빼는 소켓형 기물, 좁은 통로 앉기, 목마로 높은 곳 오르기.

기록된 의도: "탐색 시스템 학습용 기물"(11/13 기획). 이동 중 자연스럽게 탐색을 배우도록 기물과 방을 둔다. 꽝 없음. 환풍구 입구는 혼자서는 닿지 않는 높이로 잡아 2인 목마를 전제로 한다. 숙소 문 이벤트를 공통 이벤트로 넣은 이유와 TV·오작동 연출의 목적은 의도 기록 없음.

다른 안내와의 연결: 숙소 문이 닫혀 있으면 잠자기 안내(N05)가 미뤄지고 "숙소 문 열기"(N06)가 뜹니다. 1일차 밤에 잠들려면 숙소 문 이벤트를 풀어야 합니다.

5. 작업실 · 소품실 튜토리얼 (M3)

작업실과 소품실은 전실 하나를 같이 쓰고 학습 흐름도 하나입니다. 소품실에만 있는 것은 선반 안내와 포스트잇, 작업실에만 있는 것은 배관함과 회로입니다.

단계 플레이어 행동 안내 문구 완료 조건·예외
1. 문 발견 전실 문 5m 안에 처음 접근 잠긴 문 / 잠긴 문을 열려면 전력이 필요합니다. 전력을 공급할 도구를 찾아보세요. 8초, 1회
2. 배터리 찾기 로비 쓰레기 더미에서 배터리 획득 없음 배터리는 1개뿐
3. 배터리 꽂기 배터리를 들고 동력 소켓에 F(로비 쪽에서만) 동력 소켓 — 배터리 꽂기. 빈손이면 "전력이 부족합니다. 동력원을 찾아 연결하세요." 문이 위아래로 열리고 알림 조명 초록. 빼면 닫힘
4. 문 통과 열린 문을 바깥에서 안쪽으로 지남 잠긴 문 / 잠긴 문을 열린 채로 유지하려면 전력을 끊어 문을 고장내거나, 배터리를 삽입해야 합니다. 1회. 회로를 이미 고장 냈으면 안 뜸
5. 소품실 진입 소품실 방 안으로 들어섬 소품실 선반 / 선반에 기물을 보관합니다. 보관된 기물은 게임 종료 전까지 유지됩니다. 선반 클로즈업 4.3초
6. 배관함 부수기 작업실 동벽 배관함에 F 길게(맨몸 4.5초) 또는 뽑개 배관함 · F키로 상호작용 하기 회로가 드러남
7. 회로 부수기 회로에 F 길게(맨몸 4.5초) 또는 뽑개 회로를 망가뜨리는 중... 조명 3초 깜빡임, 문이 3초 여닫히다 열린 채 고정, 알림 조명 노란색
8. 상점 해금 없음 해금 전: 작업실과 소품실을 개방하지 않아 구매할 수 없습니다. 회로 고장 뒤 공연 기물 4종 구매 가능

가르치는 것: 전력으로 여는 문과 동력 소켓, "임시로 열기(배터리)"와 "영구히 열기(회로 파괴)"의 차이, 맨몸 부수기, 보관용 선반. 소품실 바닥의 포스트잇은 관리실 컴퓨터 암구호 단서입니다.

기록된 의도: 힌트는 "배터리 삽입으로 문이 열리고 안으로 들어올 때", "문을 열고 입장한 다음에" 나와야 한다(11/15). "잠긴 문" 설명은 작업실·소품실에서만 쓰고 숙소 문은 제목을 따로 둔다(11/17). 공연 기물 구매를 이 문 뒤에 묶은 이유는 의도 기록 없음.

8. 확인이 필요한 것

문구 불일치

  • S03: 문구 파일은 "[T]로 기물을 내려놓거나"로 고쳤지만 화면에는 옛 조작 "[F]를 길게 눌러 기물을 버리거나"가 나옵니다
  • G01, G02, G06a, G06b, G09, G11, G11A, N01~N05, S01, S02: 문구 파일과 화면 문구가 다릅니다. 어느 쪽을 정본으로 할지
  • 화면 문구의 "단원", "방장", "감시자들": 확정 용어(공연 준비자)와 다릅니다
  • 추격자 안내 "공연장까지 가야 합니다"는 초안입니다. 게임 목표(탈출) 안내 정리가 남아 있습니다
  • G12(탈출로 문 2인 상호작용): 탈출로 문이 자동으로 열리게 바뀌어 맞지 않습니다
  • 인간대포 해금 문구 "연습실로 옮겨졌습니다": 자유 연습 조건과 맞지 않습니다

결정이 필요한 것

  • 재노출 규칙 통일: 대기실 튜토리얼은 게임을 끌 때까지 1회, 기믹 안내는 새 게임마다, 숙소 연출은 세대 유지·새 게임 재생, TV 오작동은 실행 중 1회로 제각각입니다
  • 인간대포 리허설 이수 기록이 같은 실행의 새 게임에서 초기화되지 않는 문제
  • 목마 탄 상태로 환풍구 부수기를 허용할지
  • 숙소 문 안내 판이 오른쪽 퀘스트 패널에 가려지는 문제
  • 밤 정비 삭제 뒤 잠자기·숙소 문 열기 안내(N05, N06)를 어떻게 할지
  • 기획 의도 빈칸: 구역 잠금의 이유, 숙소 문 공통 이벤트와 TV 연출의 목적, 공연 기물 구매를 전기 문 뒤에 묶은 이유

플레이 확인이 남은 것

여럿 접속 상태의 숙소 문 연출, 녹슨 휴대 절단기로 실제 배선 절단, 발견 연출 동시 재생, TV 여러 명 동기화, 구역 잠금 중 2인 목마로 넘기 시도, 잠긴 문 안내가 튜토리얼 전에 안 뜨는지, 소켓 교체 뒤 배터리 꽂기, 연습실 그네에서 착지 발판까지의 거리.
