2. 기획 의도

2.1 제작 목적

  • 게임 컷씬으로 사용한다. 서커스장에 갇힌 단원들이 겪은 일을 대사 없이 영상 기록으로 전달한다.
  • 낡은 비디오테이프에 녹화된 기록물로 만든다. 화면은 치지직거리고 화질은 온전하지 않다. 소리는 없다.
  • 짧은 애니메이션으로 만든다. CS_01은 20~30초, CS_02·CS_03은 30~40초를 기준으로 한다.
  • 컷은 3~5초로 짧게 끊는다. 컷끼리 빠르게 스쳐 가고, 중간중간 필름이 끊긴다. 장면을 설명하지 않고 스쳐 보여 준다.
  • CS_01은 서커스장이 어떤 곳인지 밖에서 보여 준다. 끌려와 강제로 공연하고 실패하면 벌을 받는 곳이다.
  • CS_02·CS_03은 같은 사건을 단원 한 명의 눈으로 다시 보여 준다. 벌받던 단원들이 어떤 사이였고 무엇을 하려 했는지를 드러낸다.
  • 세 편은 같은 캐릭터, 같은 규칙, 같은 톤을 쓴다. 뒤 편은 앞 편의 동작과 구도를 재사용해 같은 순간을 다른 시점으로 본다는 연결을 만든다.

3.2 연출 규칙

항목 규칙 의도
화질 노이즈, 색 번짐, 줄 밀림을 화면 전체에 적용한다 오래전에 녹화된 기록물로 보이게 한다
시작·끝 지지직 화면(약 0.9초)으로 시작하고 브라운관이 꺼지듯(약 0.7초) 끝낸다 테이프를 넣고 빼는 감각을 부여한다
컷 길이·전환 한 컷 3~5초. 컷 사이에 필름 끊김(0.1~0.25초)을 넣는다 기억이 빠르게 스쳐 가고 기록이 중간중간 끊긴 인상을 만든다
소리 무음 동작과 구도만으로 읽히게 한다. 캐릭터마다 동작을 뚜렷이 다르게 준다
화면 비율 16:9 전체 화면, 1920×1080, 24fps 게임 화면을 그대로 덮는 컷씬으로 쓴다
표현 방식 컨셉아트를 잘라 관절을 움직이는 컷아웃 애니메이션 컨셉아트의 그림체를 그대로 쓴다
배경 게임 배경의 톤을 따르고 흐리게 처리한다. 도심·폐허·터널처럼 새로 필요한 배경도 흐린 배경으로 만든다 캐릭터에 시선을 모으고, 그림체가 다른 배경이 도드라지지 않게 한다
숙소 배경 침대와 캐비닛, 철골과 배관 파이프가 가득한 비위생적인 공간 게임 테마에 맞추고 단원들이 사는 환경을 드러낸다
캐릭터 귀·부리·깃털·손끝까지 잘리지 않게 넣는다. 팔다리는 관절에서 움직인다. 어색한 동작은 다른 동작으로 대체한다 잘린 그림과 끊긴 팔이 보이지 않게 한다
1인칭 CS_02·CS_03은 기록자를 화면에 넣지 않고 손만 넣는다 직접 찍었거나 직접 본 기록으로 느끼게 한다
1인칭의 손 손등이 보이게 한다. 물건을 밑에서 받쳐 들 때만 손바닥이 보이게 한다 자기 손을 내려다볼 때의 모습과 일치시킨다
REC 표시 카메라로 찍는 화면에 귀퉁이 꺾쇠, 빨간 점, 배터리를 넣는다. CS_02는 카메라를 든 컷, CS_03은 전 컷 캠코더로 녹화 중인 화면임을 표시한다
폭력 표현 채찍질은 벽에 비친 실루엣으로 처리한다 간접적으로 보여 준다. 차마 똑바로 보지 못하는 감각을 함께 준다
클로즈업·흐림 핵심 순간에 얼굴 클로즈업, 흐림, 끊김을 겹친다 소품과 배경이 눈에 띄지 않게 하고 표정에 집중시킨다
배치 물리적으로 가능한 배치만 쓴다 화면이 뒤집힌 노트북 같은 불가능한 구도를 배제한다
재사용 앞 편과 겹치는 동작·구도는 그대로 다시 쓴다 같은 순간을 다른 시점에서 본다는 연결을 만든다

4. 등장인물

4.1 까마귀 단원

  • 역할: 먼저 손을 내미는 동료. 장난기가 있다.
  • 연기: 떨어지는 고양이를 붙잡는다. 긴장한 고양이 어깨에 손을 얹는다. 사진을 찍을 때 장난스럽게 팔을 든다.
  • 사건: 외줄에서 추락해 채찍질을 당하고 쓰러진다.

4.2 고양이 단원

  • 역할: 소심하고 겁이 많다.
  • 연기: 인사는 꾸벅 숙이기만 한다. 긴장하면 웅크린다. 놀라면 쭈그려 앉는다.
  • 사건: 까마귀에게 도움을 받고, 쓰러진 까마귀를 간호한다. CS_01에서 노트에 "RUN"을 쓴다.

4.3 여우 단원

  • 역할: 계획을 세우는 사람. 진지하다. CS_03의 기록자.
  • 연기: 손은 한 번만 흔들고 바로 집중한다. 어색하면 머리를 긁는다.
  • 사건: 백지에 대고 계획을 설명한다. 동료를 먼저 보내고 혼자 남아 노트북으로 시설을 해킹한다. 단장에게 들킨다.

4.4 개 단원

  • 역할: 무뚝뚝하지만 곁에 남는 사람. CS_02의 촬영자.
  • 연기: 못마땅한 듯 두 팔을 들어 인사한다. 마지못해 사진에 낀다.
  • 사건: 카메라로 동료들을 찍는다. 채찍질을 차마 보지 못한다. 단장이 내민 카메라를 어쩔 수 없이 받는다.

4.5 서커스 단장

  • 역할: 감시하고 벌주는 존재.
  • 연기: 뒤에서 지켜본다. 화내지 않고 한숨을 쉰 뒤 채찍을 든다. 웃는 얼굴을 클로즈업으로 잡는다.
  • 사건: 단원이 무언가 하려는 순간마다 나타난다.

4.6 관객

  • 어두운 옷에 가면을 쓴 무리. 얼굴 없는 존재로 그린다. 추락한 단원을 걱정하지 않고 야유한다.

5. CS_01 「비디오테이프」 (31.7초)

5.1 기획 의도

  • 폐쇄된 서커스장을 소개한다. 소개 영상처럼 시작해 안에서 벌어지는 일을 보여 주고 경고로 끝낸다.
  • 3인칭으로 잡는다. 누가 찍었는지 모르는 영상으로 만들어 밖에서 들여다보는 거리감을 준다.
  • 실패 → 조롱 → 처벌의 구조를 반복해 이곳의 규칙을 각인시킨다.

6. CS_02 「공연자 기록」 (32.1초)

6.1 기획 의도

  • CS_01에서 벌받던 단원들이 어떤 사이였는지를 보여 준다. 어색하던 사이가 가까워지고 그중 한 명이 쓰러진다.
  • 영상 전체를 카메라를 든 개 단원의 1인칭으로 잡는다. 개 단원은 화면에 넣지 않고 손만 넣는다.
  • 외줄 장면을 두 번 쓴다. 첫 번째는 붙잡아 주고, 두 번째는 붙잡지 못한다.
  • 동료를 찍던 카메라가 마지막에 단장의 손에서 다시 건네진다. 이 영상이 왜 찍혔는지를 끝에서 드러낸다.

7. CS_03 「공연자 기록2」 (45.5초)

7.1 기획 의도

  • 여우 단원 한 사람의 이야기를 처음부터 끝까지 따라간다. 세상이 무너진 날, 서커스장에서 만난 동료, 탈출 계획, 계획이 막히는 순간이다.
  • 영상 전체를 여우 단원의 1인칭으로 잡는다. 인형탈을 쓰기 전의 일상에서 시작한다. 손은 손등이 보이게 하고, 숙소 이후는 인형탈의 손으로 그린다.
  • 앞 편과 겹치는 동작과 구도는 재사용한다. 백지 장면은 CS_02와 같은 순간을 여우의 시점으로 다시 보여 준다.
  • 탈출 장면은 바로 쓰러뜨리지 않고 비틀거리는 구간을 넣는다. 일행과 떨어졌다는 감각을 부여하는 것이 핵심이다.
  • 본편이 암전으로 끝난 뒤 보너스 컷을 붙인다. 네 사람이 한 화면에 모인 순간을 마지막에 남긴다.
