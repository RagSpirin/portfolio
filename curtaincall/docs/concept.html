1. 한 줄 설명

가축처럼 갈아치워지는 서커스 단원이 되어, 외계인 관객 앞에서 묘기를 수행하고 그 대가로 산 기구로 시설을 방탈출한다. 우리가 못 나가면 흔적만 남고 다음 세대가 새로 섞인 시설에 다시 도전한다. 언젠가 누군가는 제어실에 도달해 복수하고 나간다.

2. 플레이어가 느낄 것

친구들과 티격태격 협력 → "우리 이제 좀 한다"는 숙련 체감 → 우리는 못 나가도 다음 세대가 이어간다는 감정(※강도는 흔적의 역할에 달림) → 마침내 나가는 유종의 미와 복수의 카타르시스.

이 감정을 만드는 장치: 자유시간 타이머 / 기물 = 묘기 + 탈출 도구 / 이전 세대의 흔적 / 제어실 엔딩.

3. 규칙 (7개)

  1. 플레이어에게 N일이 주어진다 (※4~7일, 플레이테스트로 확정)
    • 세계관: 관객이 보고 싶은 건 적응 못 한 인간이 다치는 것. 단원이 숙련되어 안 다치기 시작하면 정해진 기간마다 가축처럼 폐기하고 새 단원을 들여온다. 플레이어는 이 사실을 대기실 쪽지로 알게 된다
    • 설계: 탈출 준비의 런웨이이자 데드라인. 잘하게 될수록 버려질 날이 다가오는 아이러니
  2. 하루 = 공연 N회 + 공연 사이 자유시간 (※하루 공연 수 미정)
    • 공연: 묘기 랜덤 순서 호출, 완벽 수행 채점 → 크레딧
    • 고어 배율: 실수하면 사지가 날아간다. 사지가 잘린 채 공연하면 크레딧 배율↑ + 조작 페널티. 부상은 자산
  3. 자유시간 = 정찰·힌트, 또는 탈출 커밋
    • 대기실 쪽지 확인, 뒷문 너머 정비층 정찰
    • 타이머 종료 시 무대 미복귀자 = 탈주자 → 추격자 방출. 느리지만 절대 안 멈춤. 잡히면 사망. 끝까지 안 잡히고 제어실 도달 = 탈출 성공
    • 정찰(갔다 돌아옴)과 커밋(끝까지 감)이 자동으로 갈리도록 복도 길이를 잡는다. "지금 갈까, 한 판 더 벌까"가 팀 다툼의 코어
  4. 하루 끝 = 정산 → 기물 구매 → 세이브 (※구매 시점: 밤에만 / 자유시간마다)
    • 기물을 사면 다음 날부터 새 묘기가 공연에 섞이고, 그 기물이 정비층 장애물의 해법이 된다
  5. 대기실 = 앞서 간 사람들이 남긴 것
    • 쪽지: 플레이어블이 아닌 이전 인원들이 스토리를 위해 남긴 기록. 플레이어 로그로 자동 생성하지 않는다
    • 세계관 힌트: 낙서·유품·폐기 기록 (환경 스토리텔링 → 레벨 아트)
    • ※쪽지가 이번 세대의 탈출 힌트도 주는지 미정
  6. 사망·폐기 → 새 단원
    • 사망한 플레이어는 다음 공연에 새 단원(멀쩡한 몸, 배율 초기화)으로 합류
    • 일수 소진 시 전원 폐기. 다음 런은 새 단원이 같은 대기실에서 시작. 런 하나 = 세대 하나
    • 다음 세대로 넘어가는 건 흔적뿐(재화 등 나머지는 리셋). 탈출 방법(경로별로 필요한 해법)은 세대마다 다시 섞인다
  7. 제어실 도달 = 엔딩
    • 문 닫힘·추격자 차단 → 창 너머 무대 → 무대 장치(전기톱 등)를 관객에게 → 갇힌 인간 해방 → 출구
    • 전투 시스템 없음. 기구와 무대 장치로 복수한다. 앞선 세대 전부의 복수

4. 루프 한 장

허름한 대기실(앞서 간 사람들의 쪽지 · 이전 세대의 흔적) → 공연(랜덤 묘기·채점·고어 배율) → 크레딧
   → 자유시간: 쪽지 확인 · 정비층 정찰
   → 타이머 종료
        ├ 무대 복귀 → 다음 공연 … → 하루 끝: 정산·기물 구매·세이브 → 다음 날
        └ 복도에 남음 = 커밋 → 추격자 방출
              ├ 잡힘 → 사망 → 새 단원 투입
              └ 제어실 도달 → 복수 → 탈출 엔딩
일수 소진 → 전원 폐기 → 다음 세대 (흔적만 남음 · 탈출 방법 재배치)

5. 동선

무대 ↔ 대기실(허브: 상점·쪽지 벽·취침·정산) ↔ 뒷문 너머 정비층(거대한 산업 공간 — 캣워크·배관·사육장, 장애물 3~4개 순서 배치) → 제어실(골인·안전지대)

  • 탈출 파트의 무드 = 쇼생크 탈출 · 프리즌 브레이크: 숨은 통로, 벽의 지도, 밀반입한 도구, 여러 날에 걸친 준비 → 한순간의 실행

6. 핵심 설계 의도

  • 기물 하나 = 묘기 하나 + 탈출 도구 하나. 외줄=틈 건너기, 대포=벽 파괴·자기 발사, 그네=천장 통로, 칼판=원거리 스위치, 원통=압력판. 공연과 탈출이 같은 콘텐츠를 공유한다
  • 탈출 방법은 세대마다 다시 섞는다. 장애물은 런(=세대)마다 일부만, 랜덤 순서로. 필요한 기물 세트가 매번 다르다
  • 쪽지는 스토리 장치, 세대 사이에는 흔적만. ※흔적의 역할 미정(§10)
  • 부상은 자산. 위험하게 공연할수록 돈이 빨리 모이고 몸은 망가진다
  • 숙련의 아이러니. 잘하게 될수록 관객은 식고 폐기는 다가온다. 숙련은 공연이 아니라 탈출에 써야 한다
  • 결정 지점은 하나 — 자유시간 타이머. 규칙이 단순해서 튜닝값만 바꿔도 게임이 안 깨진다

7. 세계관·톤

  • 인간은 가축, 시설은 사육장 겸 서커스장. 무대는 화려하고(빨강·금색) 뒷공간은 차갑고 무기질 — 이 대비가 기괴함
  • 관객은 외계인. 가둔 존재의 정체는 엔딩에서 드러남 (※정체·해소 정도 미정)
  • 톤: 기괴·고어 있음. 코믹 호러(무섭지만 결국 웃긴)로 봉합할지 팀 결정. ※9/23 팀 메모 "잔인하지 않은 잔혹 동화, 아기자기"와 수위 차이 있음 — 월요일 논의
  • 세대 서사: 어느 순간 인간들이 머리를 굴려 다음 팀에게 팁을 전수하기 시작했다

8. 비주얼 가이드

  • 시점 1인칭(본인 손·균형봉·발), 동료 단원이 항상 화면 안에. 성인 비율 로우폴리 + 물리 랙돌
  • 무대: 스포트라이트 무대 vs 어두운 객석(실루엣·눈빛)
  • 공간은 넓게: 대기실은 긴 방(깨진 거울·의상 랙·배관 천장), 시설은 거대한 정비층 — 컨셉아트는 와이드 앵글 설정샷 기준
  • 흑백 스토리보드·컨셉아트 14장은 팀 PR 덱(커튼콜_v2.0_팀PR.pptx)에 있음. 흐름 전달용이며 톤 결정용 아님. 컬러·톤 탐색은 팀 톤 결정 후

9. 스코프 — 수직 슬라이스

하루 분량, 대기실 하나, 정비층 하나 + 장애물 소수, 기물 두 종(외줄·대포). 이게 돌아가면 나머지는 복사. 넷코드 방식은 이 단계에서 결정.

10. 미정

  1. 톤: 코믹 호러로 갈 것인가 / 고어 수위
  2. 배경: 외계 사육 시설 / 지구 지하 시설 / 추상 공간
  3. 구매 시점: 밤에만 / 자유시간마다
  4. 묘기 선택: 완전 랜덤 / 랜덤 후보 중 팀 선택 / 세트리스트
  5. 잡힘 범위: 개인 사망 / 전원 런 종료
  6. 팀 분할: 일부 공연·일부 탈주 허용 / 전원 무대 필수
  7. 추격자와 장애물: 무시(벽 타고 옴) / 막힘
  8. 흔적의 역할: 감정 연출만 / 믿을 수 없는 힌트(이전 세대가 죽은 자리·방식) / 남는 물건(걸어둔 로프·부순 벽)
  9. 추격자·가둔 존재의 정체
  10. 스토리 쪽지의 탈출 힌트 여부: 세계관만 / 그 세대 배치에 맞춘 힌트 포함
  11. 묘기와 기물의 관계: 기물 1 = 묘기 1 / 묘기·소모 도구·기물 3층 분리 (묘기 작업 전 결정 필요)
